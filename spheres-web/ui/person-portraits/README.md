# Superseded raster studies

These files preserve built-in image-generation experiments, submitted prompts and licensed reference images from the earlier portrait pass. The user rejected the realistic/full-body raster direction and then requested actual rotatable 3D cartoon characters. No generated image in this directory is registered as an accepted or served person avatar.

The active models are in `../person-models/`, with production direction in `docs/CHARACTER_3D_ROADMAP.md` and exact-person era metadata in `spheres-web/data/person_models.json`. Reference-photo attribution remains in `references/source-review-uk-v1.json`.
