# S15 — Tactical missions and campaign results

Status: implementation complete; qualification in progress. The authorized stop is S15. S16 remains planned.

Air command now connects owned aircraft, saved squadrons, funded bases, routine support and two reviewed tactical orders. **Support army** requires an army in contact and augments its existing ground pressure. **Strike target** adds paid aircraft attack at an eligible enemy-held or contested province. Aircraft alone do not capture territory. Both use the campaign's existing contact and casualty resolver.

The launch review states the squadron, target, date, distance, radius, shared national force allocation and compatible ammunition requirement. One queued order reserves each squadron. Launch rechecks actual basing, access, range, funded upkeep and physical stores. Changed circumstances produce a dated held result instead of an invisible launch.

Every front shares one opening ammunition plan. Competing missions receive proportional coverage from the same finite compatible family; operations makes its one normal ammunition debit. The flight ledger writes off only participating aircraft, using the Arsenal's existing whole-unit loss carry, and records dated mission results. Unassigned, refitting, rebasing and servicing aircraft are excluded. Survivors need funded routine service before another mission.

The S12–S15 implementation is qualified together because ownership, basing, support and mission settlement share the same physical property and day boundary. The acceptance record will include exact source, native and browser results, disclosed scenario inputs, full-world comparisons and review images. Development failures remain documented rather than being counted as passes.

G3 and CP1 remain unearned. Fighter/Defend skies work begins at S16; this run stops before that session. Historical character coverage, wider campaign qualification, performance certification and human playtesting retain their existing roadmap requirements.
