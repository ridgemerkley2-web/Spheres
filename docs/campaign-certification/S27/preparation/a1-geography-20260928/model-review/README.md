## One unresolved design question, not an implementation recommendation

Original `BUGS.md:3091` explicitly acknowledges that the chosen economic-crisis route does not represent certain military interventions without that kind of public crisis. The current programme-veto path (`government.rs:8576`) addresses a narrow institutional conflict at an election, not every possible civilian–military dispute. This admits a model limitation, but does not establish a defective implementation or specify an additional trigger.

The remaining question is whether a **separately observable conflict over civilian executive authority** should create political disobedience despite adequate provisioning and low macro discontent. If approved as a design change, a player would need to see and influence that conflict; military funding would retain its material benefit while not automatically settling the specified dispute. A quiet, funded autonomous Army with no such dispute must be a counterexample, as must ordinary government succession, missing Army presence, strong civilian control, and a resolved crisis. The separate Algeria/programme-veto timing must not be accidentally counted twice.

No such independent dispute signal is demonstrated by these retained records. Using high removal leverage alone, lowering a loyalty ceiling, deleting the discontent guard, or forcing events in historical countries would invent the missing causal condition. Accordingly this review recommends **no source change**. A concrete design contract and independently justified trigger must come before an implementation/regression proposal and the unchanged A1–A10 checks. This is neither calibration nor campaign qualification.
