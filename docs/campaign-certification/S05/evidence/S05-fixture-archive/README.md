# Original archive qualification inputs

`qualification-fixtures.zip` contains the unchanged 28 original-active lifecycle exports and their manifest under `active/`, plus the genuine pinned-master campaign and generation record under `master/`. `archive-manifest.json` lists each entry's original SHA-256 and byte count. The zip SHA-256 is `1c3092fd5bfb3b98ce8e824663351facf4b87f19dcaa93a5e2dee4233a15bfd6`.

These are isolated QA campaigns. The original active exporters used disclosed technical/financial starting prerequisites followed by real commands and ticks. They are not player campaigns or historical balance evidence. The master campaign was generated by the pinned original master executable; it has no invented active supplier or party books.

Extract into a **new directory outside the game save directory**. For example, from a checkout containing this evidence:

```powershell
Expand-Archive -LiteralPath docs/campaign-certification/S05/evidence/S05-fixture-archive/qualification-fixtures.zip -DestinationPath ../s05-original-inputs
```

Record the absolute extracted path. Build the tested runtime revision `db9d17c8d726aa102aa143ceb3599009c558ffee` in a separate checkout with `cargo build --locked --release -p spheres-web`, then select the three ignored acceptance cases explicitly from that checkout:

```powershell
$env:SPHERES_S05_ACTIVE_FIXTURES = (Resolve-Path ../s05-original-inputs/active).Path
$env:SPHERES_S05_MASTER_ARCHIVE = (Resolve-Path ../s05-original-inputs/master/profile-industry_and_war-0.json).Path
cargo test --locked --release -p spheres-web s05_master_migration_tests::actual_pinned_master_archive_preserves_property_history_and_next_day -- --ignored --exact --nocapture --test-threads=1
cargo test --locked --release -p spheres-web s05_active_fixture_tests::original_active_company_stages_preserve_property_across_load_and_explicit_adoption -- --ignored --exact --nocapture --test-threads=1
cargo test --locked --release -p spheres-web s05_save_matrix_tests::standalone_party_v1_preserves_real_supplier_books_for_equipment_versions_2_through_5 -- --ignored --exact --nocapture --test-threads=1
```

The evidence runners record the original absolute environment paths; these must be adjusted to the new extraction location. Linux uses the equivalent process environment. Fixture hashes must be verified before and after. The separate 31-day deployment comparison uses the same original master archive and the lossless runner in `../runners/deployment-outcome/`. Its complete canonical output archives remain in the local evidence workspace; this repository retains their exact hashes, comparison results, requests and reproducible inputs rather than duplicating about 200 MB of checkpoint JSON.

The six lifetime-performance checkpoints are separate inputs described by the S01 baseline and final lifetime runner manifest. This zip does not claim to contain or certify full 1990–2035 campaigns.
