# SPHERES development entry point

The only game integration branch is `codex/campaign-certification`.
Read `ROADMAP.md`, `CONTRIBUTING.md` and `docs/AI_WORKSTREAMS.md` before choosing work.
Use the canonical status and task registers in `docs/planning/`; do not infer
current priorities from archived plans, branch names or past conversations.

For implementation, read `docs/development/ENGINEERING.md` and the relevant
contracts in `docs/design/` and `docs/reference/`. Preserve the user's campaign,
uncommitted work, deterministic rules, original evidence and acceptance limits.

Work in an isolated task checkout. Return reviewed changes to the integration
branch; do not force-push it. The dashboard is a separate publishing branch.
Check the branch archive and live-work exceptions before reviving an old branch.
